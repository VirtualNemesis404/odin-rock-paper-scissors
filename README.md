# Rock Paper Scissors

## Description
This is a Rock Paper Scissors game built using JavaScript and HTML as part of my journey through The Odin Project's Foundations course.

## Technologies Used
- HTML5
- JavaScript

## Concepts Learned
- JavaScript Basics :
    - Variables
    - Data Types
    - Conditional logic
    - Methods
    - Functions

## How to Run This Project
- Clone this repository from github to local machine.
- `cd odin-rock-paper-scissors`
- open index.html in browser
- Now go to Developer Tools and navigate to Console Tab to play the game.
